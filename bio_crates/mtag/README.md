# `mtag` — Multi-Trait Analysis of GWAS (Rust port)

A faithful Rust port of **MTAG** (Turley et al. *Nature Genetics* 2018,
doi:10.1038/s41588-017-0009-4), a method for jointly analysing multiple GWAS
summary-statistics sets to increase effective sample size per trait.

This is a **library only** — a 1:1 port of the Python reference
(`reference/mtag/mtag.py` v1.0.8). There is no CLI binary.

## Modules

| Module     | Python source                        | Contents                                                |
|------------|--------------------------------------|---------------------------------------------------------|
| `linalg`   | `_posDef_adjustment`, `cov2corr`     | posdef adjustment, MVN PDF, Jacobi eigensolver, invert  |
| `nelder`   | `scipy.optimize(Nelder-Mead)`        | generic Nelder-Mead simplex optimiser                   |
| `omega`    | `gmm_omega`, `estimate_omega`        | Ω estimation: GMM / numerical MLE / special cases       |
| `mtag`     | `mtag_analysis`                      | core MTAG conditional formula                           |
| `fdr`      | `fdr`, `compute_fdr`, `simplex_walk` | max FDR grid search                                     |
| `data`     | `load_and_merge_data`, `save_*`      | data loading, allele harmonisation, result I/O          |
| `model`    | `mtag()`                             | top-level pipeline driver                               |

## Faithfulness

- Linear algebra on [`faer`](https://github.com/sarah-ek/faer) (no LAPACK).
- Normal distribution functions via [`statrs`](https://crates.io/crates/statrs).
- Cholesky-based Ω reparameterisation (`flatten_out_omega` / `rebuild_omega`)
  exactly mirrors the Python.
- Jacobi eigenvalue algorithm for positive-definiteness checks (replaces
  `np.linalg.eigvals`).
- Nelder-Mead optimiser follows scipy's classical α=1, γ=2, ρ=0.5, σ=0.5.

## Usage

```rust
use mtag::data::{TraitData, DataConfig};
use mtag::model::{run_mtag_with_matrices, MtagConfig};
use mtag::omega::{estimate_omega, OmegaConfig};
use mtag::linalg::pos_def_adjustment;
use faer::Mat;

// 1. Load GWAS sumstats
let trait1 = TraitData::from_tsv(path1, "SNP", "Z", "N", "FRQ", "A1", "A2", None, None)?;
let trait2 = TraitData::from_tsv(path2, "SNP", "Z", "N", "FRQ", "A1", "A2", None, None)?;

// 2. Estimate Sigma (via LDSC bivariate regression — not included in this crate)
let sigma_hat: Mat<f64> = /* ... */;

// 3. Run MTAG
let cfg = MtagConfig::default();
let analysis = run_mtag_with_matrices(&[trait1, trait2], &cfg, sigma_hat, omega_hat)?;

// 4. Extract results
for p in 0..analysis.data.zs.ncols() {
    let rows = mtag::data::build_output_rows(&analysis.data, &analysis.result, p, false);
    mtag::data::write_output_rows(&rows, &output_path)?;
}
```
