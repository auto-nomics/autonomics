# 插件项目与容器开发

插件项目以 daemon 管理的单个插件工作区为单位。一个项目对应一个 Git 仓库和一个 `manifest.toml`，其中声明的多个节点共享插件镜像。项目开发内容和已激活的运行快照是不同的：修改工作区不会自动改变已注册节点。

当前基础接口：

- `GET /api/v1/plugin-projects` 列出工作区，包括 manifest 缺失、格式错误或名称不匹配的项目；错误由 `error` 字段描述。
- `POST /api/v1/plugin-projects` 接受 `name`、`environment_id`、`purpose`，通过现有插件生命周期创建绑定已批准环境的 draft 项目。
- `GET /api/v1/plugins/environments` 列出可用于创建项目的环境。

下一阶段的开发界面应围绕选中的项目提供文件浏览和编辑、环境状态、容器内命令输出、节点校验和本地激活。容器会话应单独管理其生命周期，将项目工作区挂载到容器内，明确区分开发镜像和生产节点运行快照；重启容器不能删除项目文件。镜像、挂载、用户身份、网络和资源限制需要在实现会话 API 时明确建模。现有接口尚不提供容器会话、终端或文件编辑能力。
