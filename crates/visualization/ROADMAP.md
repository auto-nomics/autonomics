# 科研绘图模块的完成标准

目标是实现开源的 BioRender Leo 类工作流，不以可编辑画布或通过固定样例测试作为完成条件。对标依据：[Leo 官方产品说明](https://www.biorender.com/product/leo-ai-figure-builder)（2026-11-10 检查）。核心体验包括围绕科学图意展开对话、草图审阅与标记、素材化构图、保持无关对象的局部修改，以及工作区内逐对象编辑。

| 能力 | 当前实现与证据 | 尚需完成或验证 |
| --- | --- | --- |
| 项目管理与持久化 | visualization Store；不可变修订、历史恢复；API 回归；Gateway 鉴权测试 | 项目内完整用户流程与大文档容量验证 |
| 原生对象编辑 | Excalidraw 形状、标签、箭头和图片；canvas-editor.mjs 覆盖绘制、导入、保存、导出、重载 | 持续保证第三方控件在标签切换后隐藏；复杂连接线与变形的 Agent 几何编辑 |
| 科学图意澄清 | 版本化科研计划与问题/答案历史；表单和 Agent 共用读写；待澄清项阻止生成；就绪计划编译为可审阅提案 | GPT 真实模型已通过三组件概念图的澄清与答案保留；仍需多种科学主题、多模型与缺失事实评估；结构就绪不等同于科学正确 |
| 草图与构图 | 结构化 Plan 编译为独立对象；网格与水平/垂直自动布局；反馈/跨层通道、长标签自适应；固定本地字体、字宽/字距与浏览器实测及 SVG 内嵌校验；独立面板与原生 frame、GUI 分配/审阅/移动；显式跨面板避障连线与端点跟随；当前几何整理及提案审阅；活动画布草图作为提案 | 仍需完整 Unicode 整形与中文字体一致性、旋转绑定与复杂手绘线路整理、嵌入插图、多种真实科学图的密集布局评估及真实模型布局选择验证 |
| 素材检索与精化 | NIH BioArt PNG 与 BioIcons SVG 目录适配；预览、逐素材来源许可、矢量插入与保留语义锚点的替换提案 | GPT 已通过真实目录检索、预览和替换的单例；仍需更多素材与科学匹配评估；已支持逐实例配色、前后哈希与修改记录；内部路径尚不能逐路径编辑；SVG 文字转换及更多素材兼容性需继续评估 |
| 草图标记驱动修改 | 临时圈选、对象批注；独立持久化补画、划除、强调笔迹与说明；按版本保存的合成预览和 read_markup 视觉入口 | 五轮真实测试已到达批注图读取，随后被服务额度中断；删除提案及采用仍待验证；标记列表当前仅显示最近 50 组 |
| 局部修改审阅 | 字段级操作、提案前后预览、采用/拒绝、版本冲突；并发采用测试 | 需要真实模型证明能够根据视觉和标记选择正确对象；当前采用以整份提案为单位 |
| 图像理解 | read_image/read_preview 返回 SDK 图像块；运行时视觉能力检查 | GPT 已通过读取整图并仅修改指定标签的单例；参考图重建、复杂视觉理解仍需验证 |
| 端到端工作流 | canvas-native.mjs 使用固定模型决策验证数据一致性；canvas-live.mjs 已通过 GPT 四轮澄清、草图、局部改字与真实素材替换 | 真实模型测试已保留轨迹、场景及截图；仍需批注驱动修改、真实科学案例及生产 Gateway 全会话验证；MiniMax 当前未通过 |

每项完成须有与其范围相符的证据。单元测试通过不能证明科学正确性，固定样例通过不能证明 Agent 决策质量；模型评估也不能替代数据一致性和并发测试。

后续优先补齐构图布局及真实模型验收，验证从科学图意澄清、草图标记到素材化图稿和局部修改的连续流程。继续保留正式图稿与审阅材料分离、版本明确和无关对象不变的约束。
