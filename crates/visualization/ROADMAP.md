# 科研绘图模块的完成标准

目标是实现开源的 BioRender Leo 类工作流，不以可编辑画布或通过固定样例测试作为完成条件。对标依据：[Leo 官方产品说明](https://www.biorender.com/product/leo-ai-figure-builder)（2026-11-10 检查）。核心体验包括围绕科学图意展开对话、草图审阅与标记、素材化构图、保持无关对象的局部修改，以及工作区内逐对象编辑。

| 能力 | 当前实现与证据 | 尚需完成或验证 |
| --- | --- | --- |
| 项目管理与持久化 | visualization Store；不可变修订、历史恢复；API 回归；Gateway 鉴权测试 | 项目内完整用户流程与大文档容量验证 |
| 原生对象编辑 | Excalidraw 形状、标签、箭头和图片；canvas-editor.mjs 覆盖绘制、导入、保存、导出、重载 | 持续保证第三方控件在标签切换后隐藏；复杂连接线与变形的 Agent 几何编辑 |
| 科学图意澄清 | 版本化科研计划与问题/答案历史；表单和 Agent 共用读写；待澄清项阻止生成；就绪计划编译为可审阅提案 | GPT 真实模型已通过三组件概念图的澄清与答案保留；仍需多种科学主题、多模型与缺失事实评估；结构就绪不等同于科学正确 |
| 草图与构图 | 结构化 Plan 编译为独立对象；网格与水平/垂直自动布局；反馈/跨层通道、长标签自适应；固定本地 Latin/Greek/CJK 字体、原 Latin 度量与轮廓保留、字宽/字距与浏览器实测、中文断行及 SVG 实际字体子集字形覆盖校验；独立面板与原生 frame、GUI 分配/审阅/移动；显式跨面板避障连线与端点跟随；当前几何整理及提案审阅；活动画布草图作为提案 | 仍需未覆盖字形与复杂 Unicode 整形、旋转绑定与复杂手绘线路整理、嵌入插图、多种真实科学图的密集布局评估及真实模型布局选择验证 |
| 素材检索与精化 | NIH BioArt PNG 与 BioIcons SVG 目录适配；预览、逐素材来源许可、矢量插入与保留语义锚点的替换提案 | GPT 已通过真实目录检索、预览和替换的单例；仍需更多素材与科学匹配评估；已支持逐实例配色、前后哈希与修改记录；已支持按文件快照编号选择路径、局部填充/描边/透明度系数提案及编号视觉入口；已支持路径在 SVG 根坐标中的平移与预览手柄拖动；已支持端点/Bezier 控制点的根坐标拖动、稀疏修改和拓扑保留提案；增删点、曲线自动平滑及拆成原生画布对象尚未实现；SVG 文字转换及更多素材兼容性需继续评估 |
| 草图标记驱动修改 | 临时圈选、对象批注；独立持久化补画、划除、强调笔迹与说明；按版本保存的合成预览和 read_markup 视觉入口 | 五轮真实测试已到达批注图读取，随后被服务额度中断；删除提案及采用仍待验证；已支持完整历史游标翻页及待处理/已处理筛选；仍需真实模型验证长期多轮审阅 |
| 局部修改审阅 | 字段级操作、提案前后预览、采用/拒绝、版本冲突；提案显式关联审阅意见、用户选择采用并完成、同一事务提交与失败回滚；并发采用测试 | 需要真实模型证明能够根据视觉和标记选择正确对象；当前采用以整份提案为单位 |
| 局部放大 | 复用原始 SVG/PNG 文件的原生 crop 快照；版本、哈希、裁剪与许可保留；HTTP image-info/insets 与 Agent image_info/inset 生成待审阅提案；组合旋转、镜像、已有裁剪的几何与源文件不变测试；GUI 图片框选/比例输入、提案采用、重载、真实 BioIcons SVG 裁剪导出及独立浏览器渲染验证；删除锚点清理匹配的区域框/引导线，双放大图和独立注释保护测试；来源状态比较与显式刷新提案，保留 ID、标题、边框和样式，记录前后哈希及版本，局部文件/裁剪修改保护、源图缺失检查；真实 BioIcons 改色/旋转/镜像源图的刷新、采用、局部裁剪替换选择及刷新后独立 SVG 渲染验证；保持原图方向的框选，任意旋转+双向镜像+已有裁剪的 GUI 拖动、参照点颜色、精确 crop 和独立 SVG 像素一致性校准 | 更多真实科学图片及非标准手工变形仍需评估；当前为固定快照，源图移动或修改不会自动同步区域框或刷新放大图；源图自动联动及复杂手工变形的刷新仍需实现；GUI 原生 Delete 暂遵循普通对象规则，整组清理使用删除放大图提案 |
| Agent 画布上下文 | 统一工作台和绘图交接复用有界选区摘要；变换/裁剪/端点、放大图角色及不明确归属、总数/截断标志；false/已删除项排除；重载清空与就绪标志；同一选区连续未保存移动实时发布；纯契约及原生浏览器/工作台上下文回归 | 大文档高频交互性能及真实模型理解这些上下文的行为仍需验证；摘要截断时须缩小或明确完整选区，不能从保存文档推断临时选中状态 |
| 既有组件整理 | arrange 待审阅提案：六向对齐、双向分布及编辑器拥挤退化；原生组合/语义素材/标签、框架内容一次移动；旋转椭圆/菱形边界；直线绑定与标签跟随；审阅意见关联及原子采用；手绘点列/笔压与无抖动折线组合，原生绑定文字位置，内部连接刚性检查；单元、工具与原生浏览器几何/重载验证 | 真实模型选择组件与整理模式、密集科学图效果尚需验证；粗糙/曲线/肘线边界、旋转箭头绑定文字、两端分别移动的复杂连接和自动避障仍需适配；手绘原生点边界不等于笔刷像素外缘 |
| 候选图视觉反馈 | 按需请求与保持打开的画布后台渲染；独立候选 PNG/SDK 视觉块、JSON 字节哈希、基础/当前版本与状态；绑定修复/箭头文字、科学字体实际哈希；首次成功不可覆盖、失败显式重排；存储/HTTP/工具及浏览器回归，拒绝缺失资源并禁止正式图回退 | 无界面渲染、基于候选的直接增量修订，以及真实模型检查并纠正候选图仍需实现或验证 |
| 图像理解 | read_image/read_preview 返回 SDK 图像块；运行时视觉能力检查 | GPT 已通过读取整图并仅修改指定标签的单例；参考图重建、复杂视觉理解仍需验证 |
| 端到端工作流 | canvas-native.mjs 验证数据一致性；canvas-gateway.mjs 在编译后的 GUI 与完整 Gateway/RuntimeHost 中，以固定模型决策完成真实登录/SSE、四轮对话、11 次工具调用、真实截图/标记图、提案采用、历史及源文件导出；canvas-live.mjs 已通过 GPT 四轮澄清、草图、局部改字与真实素材替换 | 真实模型测试已保留轨迹、场景及截图；仍需真实模型的批注驱动修改、真实科学案例及生产 Gateway 全会话验证；MiniMax 当前未通过 |

每项完成须有与其范围相符的证据。单元测试通过不能证明科学正确性，固定样例通过不能证明 Agent 决策质量；模型评估也不能替代数据一致性和并发测试。

后续优先补齐构图布局及真实模型验收，验证从科学图意澄清、草图标记到素材化图稿和局部修改的连续流程。继续保留正式图稿与审阅材料分离、版本明确和无关对象不变的约束。
