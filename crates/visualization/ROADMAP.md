# 科研绘图后续工作

当前交互采用 Agent 直接编辑共享画布；每次修改立即生效并进入版本历史。候选与人工采用机制已移除。

后续优化重点：

1. 用普通自然语言任务测量端到端耗时、模型轮次、失败恢复次数与用户二次修正次数；固定模型、场景和素材缓存条件做前后对比。
2. 减少多素材任务的查询与插入往返，提供跨素材的原子批量操作。
3. 将布局意图映射为确定性的局部排版，降低 Agent 手算坐标的需要。
4. 为没有打开画布的任务提供一致字体与素材行为的服务端渲染。
5. 改进并发本地/Agent 编辑的冲突恢复体验；当前通过版本校验和保留本地编辑避免覆盖。
6. 测量 SVG/图像实际显示、长标签、连线路由和多分面图的视觉质量，而不只依赖几何检查。

科学内容、图标适用性和来源质量仍需单独评估。通过直接编辑链路测试不等于达成出版级绘图质量。
