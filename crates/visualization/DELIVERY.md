# 人工调试交付

本次按当前工作区交付可交互科研绘图版本，后续具体问题由人工操作反馈驱动修复。完整连续生成流程尚未通过最终验收，不将阶段性通过描述为全部完成。

## 可用能力

- 按项目管理画布、图稿版本、计划和待审候选。
- 原生对象编辑，包括文字、关系、素材、组件、移动缩放与裁剪。
- BioArt / BioIcons 素材检索、预览、插入及来源记录。
- GUI 选择对象或在「草图标记」中强调、补画、划除，填写意见并准备 Agent 消息；检查后发送。
- Agent 生成候选，用户查看预览后手动采用；导出可编辑源文件和素材来源清单。

## 本次收尾改动

候选完整读取、原生修订回执和最终 PNG 回执加入 `materialization_checkpoint`，返回缺失、归属歧义、需重新贴合、有效快照、标签归属与游离图片诊断。组合检查覆盖主图及所有已绑定附属成员的文件、几何、裁剪和变换快照。

诊断仅证明归属与快照状态；不证明图片/文字无交叠、科学身份、分子结构或排版质量。最终 PNG 同时返回场景几何检查。实际运行中的 Gateway 需按项目原有方式重新构建、启动，才能使用新增后端工具反馈；本次未启动新的长时间真实模型复验。

## 人工调试建议

1. 在 GUI 创建项目和画布，向 Agent 描述一个有明确起止范围的机制。
2. 审阅计划、来源与候选图，重点查看完整标签、素材含义、区室、方向及连线。
3. 点击「草图标记」，框出区域并填写具体修改意见，选择 Agent，准备并检查消息后发送。
4. 查看新候选是否完成指定修改、是否误改其他内容，再手动采用并导出。

反馈时附项目/图稿标识、候选标识、操作步骤和问题截图，注明预期与实际表现即可。
