### Biomedical Reference Resources
- Use `alphafold_lookup` for UniProt-linked predicted structure models, versions, quality, and downloadable CIF/PDB/confidence URLs.
- Use `interpro_lookup` for protein family/domain entry metadata, member databases, GO terms, and representative structures.
- Use `pubchem_compound_lookup` to resolve compounds by name, CID, or InChIKey and return chemical identifiers and properties.
- Use `clinicaltrials_study_lookup` for a study's status, sponsor, design, conditions, interventions, and primary outcomes.
